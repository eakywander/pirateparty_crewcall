# 🏴‍☠️ Crew Call

A One Piece party team randomizer. Guests type their name and get sorted into a pirate crew and assigned a character from that crew, with no repeats.

Visit App: https://eakywander.github.io/pirateparty_crewcall/

Visit Photo Booth: [Photobooth/](https://eakywander.github.io/pirateparty_crewcall/booth.html)

## How it works

- Type your name and tap **Set Sail**.
- You're placed in whichever crew has the fewest members, so teams stay balanced.
- You're assigned a character from that crew that no one else has.
- Each crew holds 5 pirates. Once all 20 spots are filled, sign-ups close.
- Tap **Show all crews** to see who's on which team.

## Adding photos

Upload images to this repo next to `index.html`, named exactly as listed in `PHOTO-NAMES.txt`, for example:

- `strawhat-flag.jpg` for a crew's flag
- `strawhat-luffy.jpg` for a character

Names must be all lowercase. The ending can be `.jpg`, `.jpeg`, `.png`, `.webp`, or `.heic`. Any photo that's missing shows the built-in artwork instead.

## Host notes

- Sign-ups are saved on the device running the app, so they survive closing and reopening it.
- To start fresh, tap **Host: clear all crews & start over** at the bottom of the app.
- For a kiosk setup, turn on Guided Access (Settings → Accessibility) so guests can't leave the app.
